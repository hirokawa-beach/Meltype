# 全国郵便番号データの分類と整形

対象は日本郵便の全国 UTF-8 データ、2026 年 9 月 30 日更新版。集計対象は元 CSV の 124,526 レコードで、異なる郵便番号は 120,720、重複を除いた番号・地域・町域原文の組は 124,525。原文の組の完全一致検査と、同じ ZIP からの辞書再生成のバイト一致検査を実施した。

本ツール独自の排他的な機械分類であり、日本郵便の公式分類ではない。優先順位は未掲載・市区町村のみの説明、除外・限定条件、京都の位置説明、範囲表記、その他の括弧・特殊語、通常の町域。分類と安全に分離できるかの判定を分け、原文は常に保存する。

「その他」には、建物の階 3,437 件、単一方角を括弧で示す町域 21 件、市区町村のみの説明 39 件を含む。サブ分類は説明用で、上の 6 分類を二重計上しない。

## 京都の展開

258 レコードから 1,133 個の通り名・位置説明を抽出した。京都府京都市の住所、単一の末尾括弧、読める方向表現・終端という条件を満たす場合に限る。未知の項目が混じる列挙は部分的に展開せず、町域全体を保持する。

`6028368` は「京都府京都市上京区北町」を基本住所にし、21 個の位置説明を保存した。基本住所・通り名＋町名・通り名のみをすべて ON にすると住所候補は 43 個、元の番号と全角番号を含む一覧は 45 個になる。

町名との結合を控えた位置説明は 4 個。`6050011` の「三条大橋東４丁目」は通り名のみを生成し、「三条大橋東４丁目七軒町」は生成しない。一方「三条大橋東入４丁目」は確認できる終端なので町名付きも生成する。`6020842` の「…下る西」「…２筋目西」、`6050034` の「三条通白川橋東４丁目」も町名を結合しない。

## 大字・小字の展開

番地を省き、角括弧内を省略し、名前付き引用を半角空白でつなぐ整形を適用し、123レコード・318個の地名を分離した。主分類ではその他111件・範囲10件・除外2件に相当する。分類件数は維持している。

小字は最大31個（0210102萩荘）。9692701の17個・9660501の16個・9660401の7個は番号ごとに保持。小字候補は初期ONで、小字と大字のみの候補は同時に出さない。OFFにした場合だけ、大字までの候補を出す。すべての候補を有効にしても最大66件は維持する。

9790622の「前川原２３２〜２４４、３１１、３１２、３３７〜８６２番地〔東京電力福島第二原子力発電所構内〕」から小字名「前川原」を抽出する。番地・亀甲括弧は原文詳細に保存し、住所には挿入しない。

3703321の「泉沢（烏帽子「榛名湖畔」、烏帽子国有林７７林班）」も同じ列挙処理で分離する。林班番号は番地と区別し「烏帽子国有林７７林班」を候補に残す。9492141の「妙高山国有林第２８班」も番号・単位を保持する。未知の追加説明が付く場合は無理に分離しない。

3703311の「烏帽子「榛名湖畔」」は「烏帽子 榛名湖畔」にする。この行の小字起番フラグは0なので、数値条件でない名前付き引用を追加の手掛かりとして扱う。9996652の「渡戸沢「筍沢温泉」」も同様。引用内に数字のある除外条件は挿入せず原文詳細に保持する（0330071犬落瀬下久保など）。

フラグ・引用を含む表記の行政上の意味を断定しない。読み仮名（4740057共和町）、同名大字の区別（4850026大山）、地割で範囲を示す大字、未知の説明や不均衡な括弧は連結しない。処理できない項目を含む列挙は部分展開せず原文を保持する。元CSVの情報と、設定に応じた挿入文字列を分けて扱う。

根拠: [日本郵便のデータ説明](https://www.post.japanpost.jp/service/search/zipcode/download/readme.html)、11列目と注記※4。数字・角括弧の省略と引用の半角空白への変更は本機能の表示ルールであり、元データを訂正するものではない。

## 空港内の所在地の展開

17レコードから18個の所在地候補を生成した。2820011の三里塚は「御料牧場」と「 成田国際空港内」の接尾辞を持つ。他の16レコードは単一の「 成田国際空港内」。空港の前には半角空白を挟み、牧場名は直接町域に連結する。原文列は変更しない。

主分類ではその他17件に相当する。小字表示ONでは所在地だけ、OFFでは町域まで。未確認の混合説明を含む列挙は部分生成しない。「空港南町」「羽田空港」など、普通の町域名は従来どおり保持。

## その他の施設名の展開

12レコードから25個の施設・所在地候補を分離した。主分類の内訳はその他9件・範囲2件・除外1件。再度公園を含む6511102は従来の小字分類から施設混在分類へ移したため、小字分類は123レコード・318地名になる。

6980051石見空港、4442451足助高等学校、7392621賀茂精神医療センター、9690106八雲神社は町域の後ろに半角空白。0240341湯田ダム管理事務所は町域の４４地割を、4070311の施設は町域の８２４０−１を保持する。4091211の番地のみの項目は省略し、施設名を候補に残す。施設名に含まれる数字は省略しない。

「寺」「園」「荘」という語尾だけで施設と断定しない。地名としても使われる「寺前」「観音寺」「長楽寺」「大学村」等は従来の処理を維持。数字付きの所在地に引用された寺名（7200845聖宝寺）は施設の記載と判断する。日本郵便の[原文の掲載ページ](https://www.post.japanpost.jp/cgi-zip/zipcode.php?city=1342070&id=131157&pref=34)も確認した。

「たかね荘」は[北杜市公式資料](https://www.city.hokuto.yamanashi.jp/docs/28291.html)で宿泊施設としての扱いを確認した。既に旧施設として紹介される場合も、郵便データの名称は変更しない。「すずらん荘」の施設としての判断は、同じ市町村・掲載番地にある[甲州市公式観光情報](https://www.koshu-kankou.jp/map/m4943.html)との照合による。この2名称は都道府県・市区町村の組で適用範囲を限定し、現在の名称への置換はしない。

列挙は全項目を解釈できた場合にのみ分離し、未確認の説明は部分生成しない。角括弧内の説明を無視する既存ルールを先に適用するため、9790622の発電所構内を再び候補に出すことはない。

## ビルと階の展開

数値階 3,351 件と「地階・階層不明」86 件、計 3,437 件・86 棟を分離した。同じ地域の通常町域・安全に分離した範囲/除外条件の町域を用い、全棟を照合できた。「次のビルを除く」は33件あり、町名と除外注記に分離する。通常・範囲・除外・京都などの主分類件数は変わらず、建物の詳細分類のみ更新した。

ビル名に英字を含むものは24棟。全角 ASCII を半角に変換するが、原文列は変更しない。階数は辞書内では半角で保持し、候補生成時に設定を反映する。未認識の階表記や町域未照合の建物は原文のまま。将来のデータ更新でも、この条件を満たす場合だけ整形する。

## 原文保持を選んだケース

- `6308037` 中町の長い数値列挙: 単位が明記されず、番地・小字・町域名の区別を断定できないため原文保持。
- `0802333` 美栄町（西５〜８線７９〜１１０番地）: 方角と線番号を含む複合範囲なので原文保持。
- `0330071` 犬落瀬の部分除外: 小字名だけを候補にし、数字付き除外条件は原文詳細に保持。
- 未認識の建物・階表記、南／北、解釈できない地名や仮名の小字列挙、入れ子の括弧、未認識の京都表記: 説明と固有の住所部分を断定できないため原文保持。

安全に分離した範囲・除外条件も、町域原文を詳細に保持し「範囲条件あり」「除外・限定条件」の短い注記を表示する。通常の辞書の意味表示を OFF にしても住所の条件は確認できる。同じ挿入文字列になる行をまとめる場合、原文・条件はすべて結合して保持する。異なる郵便番号同士は統合しない。

## 辞書と運用

schema 4 の UTF-8 TSV を gzip にし、共通 Core に埋め込む。8 列は番号、都道府県＋市区町村、町域原文、分類、分離した町名、位置説明と結合可否の JSON 配列、建物の町域・名称・階数の JSON 配列、小字・所在地の接尾辞 JSON 配列。Windows の設定画面には既存の Settings 属性を利用して 4 つの ON/OFF と階数の全角・半角選択を追加。macOS・Linux は同じ config.json 項目を使い、既存方式と同じく入力サービスを再起動して反映する。

未認識の新表記を自動的に補正・推測しない。公式データ更新後は分類件数・例・保持率を確認して再生成する。事業所番号・逆引き・旧町名や表記揺れの補正は対象外。通り名のみを選んだときに町名・番地を補完することもない。

提供元: [日本郵便の全国 UTF-8 データ](https://www.post.japanpost.jp/service/search/zipcode/download/utf-zip.html)。利用条件: [郵便番号データの説明](https://www.post.japanpost.jp/service/search/zipcode/download/readme.html)。元 ZIP と生成物のハッシュ、分類件数は dictionaries/postal-codes.metadata.json に記録する。
